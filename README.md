# Bookwise 📚

## Overview

Bookwise is a web application built with pure PHP following an
MVC-inspired architecture. The project was created to practice
application structure concepts such as routing, controllers, views, and
separation of concerns without using frameworks.

It allows users to manage and explore books while demonstrating clean
code organization and backend fundamentals.

------------------------------------------------------------------------

## Purpose

The main goal of this project is to:

-   Practice building a web application from scratch
-   Implement a simple routing system
-   Apply MVC concepts in plain PHP
-   Improve code organization and maintainability

------------------------------------------------------------------------

## Features

-   Book management (create, list, update, delete)
-   Custom routing system
-   Controllers handling business logic
-   Views for UI rendering
-   Organized project structure

------------------------------------------------------------------------

## Tech Stack

-   PHP
-   HTML
-   CSS
-   MySQL or SQLite
-   MVC-style architecture

------------------------------------------------------------------------

## Getting Started

### Requirements

-   PHP 8+
-   Web server (Apache, Nginx, or PHP built-in server)
-   Database

### Installation

git clone https://github.com/bcampagnoli/bookwise.git 
cd bookwise

### Run locally

php -S localhost:8000 -t public

Open in browser: http://localhost:8000
